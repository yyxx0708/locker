# Locker 使用手册

版本 1.7 · 适用于 Android 8.0 及以上

---

## 1. 这是什么

Locker 是一个**只在本机使用**的多人物佩戴计时与事件记录工具。

它能做的事：

- 为多个人物分别记录每一次「戴上 → 取下」的精确时间，形成各自的佩戴分段
- 每个人物独立计时，可以同时处于佩戴中，互不影响
- 按当前人物累计佩戴时长，按月 / 年统计
- 记录事件（内置锁射 / 开锁射精，也可自定义名称与颜色）
- 在月历的日期详情中上传每天的照片，照片会作为当天格子的背景
- 每个人物每天固定一个 5 位随机数
- 数据仅保存在本机，可导出 JSON 备份（包含全部人物与事件类型）

桌面名称是 **Locker**，图标是一把钥匙。

## 2. 安装

### 2.1 直接安装

1. 把 `Locker-1.9.apk` 传到手机（数据线、聊天软件、网盘均可）
2. 在手机上点击 APK
3. 如果系统提示，允许「安装未知来源应用」
4. 完成安装

### 2.2 通过电脑安装

手机开启 USB 调试并连接电脑后：

```powershell
adb install -r Locker-1.9.apk
```

### 2.3 升级

- 以后的新版本直接覆盖安装即可，**不要先卸载**
- 覆盖安装会保留全部数据；旧版本数据会自动升级（1.1 的记录归入默认人物「我」）
- 旧版本导出的备份仍可导入 1.7；旧备份没有每日随机数，导入后会按当天重新生成
- 1.7 导出的备份包含多人物、自定义事件类型与每日随机数，旧版本无法导入
- 卸载 App 会删除本机数据（提前导出备份）

系统要求：Android 8.0（API 26）及以上。

## 3. 界面总览

底部有三个标签：

| 标签 | 用途 |
|---|---|
| **主页** | 切换当前人物、锁上 / 开锁、查看本次时长、记录事件 |
| **统计** | 当前人物的月 / 年汇总、月历（可显示每日照片）、分段与事件明细 |
| **打卡** | 显示实时日期时间、当前人物每天固定的 5 位随机数、上传 / 更换今日照片 |
| **设置** | 人物管理、事件类型管理、外观切换、导出 / 导入备份、关于 |

主页和统计页顶部都有人物切换条，当前人物会在三个页面之间共享。

## 4. 人物

### 4.1 当前人物

主页顶部和统计页顶部都有人物切换条。点按人物名字即可切换当前人物；新建人物请到设置页。

当前人物决定：

- 主页的佩戴状态、本次时长和「锁上 / 开锁」作用于谁
- 记录的事件归属于谁
- 统计页显示谁的数据

选择会被记住，下次打开 App 仍停留在上次的人物。

### 4.2 新建人物

进入设置 →「人物」，点击标题右侧的 **加号图标**。

名称不能为空、不能与已有的人物重名，最多 20 个字符。新建后会自动切换到该人物。

### 4.3 改名、切换与删除

进入设置 →「人物」：

- 点按某一行或左侧圆点：切换当前人物
- 点铅笔按钮：改名
- 点垃圾桶按钮：删除

删除人物会**连同该人物名下的全部分段和事件一起删除**，无法恢复。App 至少保留一个人物，因此最后一个人物不能删除。

### 4.4 同时佩戴

不同人物可以同时处于「佩戴中」。每个人物各自累计本次时长：

- 主页一次只显示当前人物的计时
- 切换到另一个人物，即可看到另一个人的状态与时长
- 一个人物「开锁」不会影响其他人物

## 5. 基本使用

### 5.1 开始佩戴（锁上）

1. 打开 Locker，停在「主页」
2. 确认顶部当前人物是自己要操作的人
3. 点击 **「锁上」**
4. 在弹出的二次确认窗口中再点 **「锁上」**
5. 状态变为「佩戴中」，并实时显示本次已持续时长
6. 之后可以退出 App、锁屏、重启手机，计时会按时间戳继续

> 如果锁上时已经是过去的时间，先点「锁上」，再到统计页编辑这一段的戴上时间；或者直接用「补录」创建一段历史记录。

### 5.2 结束佩戴（开锁）

1. 确认顶部当前人物
2. 主页点击 **「开锁」**
3. 在弹出的二次确认窗口中再点 **「开锁」**
4. 该人物的当前分段结束，状态变为「未佩戴」；其他人物的计时不受影响
5. 下次再点「锁上」会开始该人物的一个新分段

### 5.3 记录事件

主页下方会列出所有事件类型（内置两项 + 自定义类型），每个按钮左侧有该类型的颜色圆点。

事件会记录到**当前人物**名下，记录前请确认顶部人物。点击后弹出记录窗口：

1. 顶部可切换事件类型（自定义类型也会出现在这里）
2. **日期**、**时间** 分开显示，点击各自修改
3. **「现在」** 可一键设为当前时间
4. 备注可选
5. 点「保存」

事件与佩戴状态相互独立：记录事件不会自动开始或停止计时。计时始终由你手动锁上 / 开锁。

### 5.4 修改或删除事件

1. 进入「统计」
2. 在「事件明细」中找到该事件（按日期分组）
3. 点按事件即可修改类型、时间、备注
4. 窗口左下角可删除；删除前会二次确认

### 5.5 管理事件类型

进入设置 →「事件类型」：

- **加号**：新建自定义类型，填写名称并从色板选择统计颜色
- **铅笔**：修改名称 / 颜色；内置「锁射」「开锁射精」也可以改
- **垃圾桶**：仅自定义类型可删除

规则：

- 名称不能为空、不能重名，最多 20 个字符
- 颜色用于统计汇总、年柱状图、月历圆点和事件列表
- 删除自定义类型会**连同所有人物名下该类型的事件一起删除**，无法恢复
- 内置类型保留，只能改名改色，不能删除

### 5.6 打卡：随机数与今日照片

底部「打卡」标签包含：

**实时时间**

- 显示当前日期和时分秒，例如「2026年11月12日 19:42:05」
- 每秒刷新

**5 位随机数**

- 每个人物每天固定一个 5 位数字，范围 10000–99999，不以 0 开头
- 当天首次打开 App 时为当前人物生成；切换到其他人物时，如果该人物当天还没有号码则生成
- 当天内**不可更换**
- 同一天不同人物的号码不同
- 切换当前人物后，随机数会随人物切换
- 号码会保存在本机，并进入 JSON 备份；换手机恢复后当天号码保持不变

**今日照片**

- 照片归属**当前人物**，会显示在月历今天的格子里
- 支持 **拍照** 或 **从相册选择**
- 今天还没有照片时显示「上传今日照片」
- 今天已经有照片时只显示「今天已上传照片」，按钮变为「更换今日照片」；选好新照片后会二次确认
- 只能上传**今天及之前**的照片；今天之后的日期在统计页里为只读

## 6. 分段管理

### 6.1 什么是一个分段

某个人物一次「戴上 → 取下」之间的连续时间，就是该人物的一个佩戴分段。

- 每次重新戴上都会开启当前人物的新分段
- 统计中的佩戴时长是当前人物各分段时长之和
- 同一人物同一时刻只能有一个佩戴中的分段
- 不同人物可以同时各有一个佩戴中的分段

### 6.2 补录过去的分段

适用于：安装 App 前已经戴了一段时间、忘记按按钮等。

1. 进入「统计」，先切换到要补录的人物
2. 找到「分段明细」标题
3. 点击右侧 **「补录」**
4. 设置「戴上时间」和「取下时间」
5. 如果现在仍在佩戴：打开 **「仍在佩戴中」** 开关，此时不需要填取下时间
6. 点「保存」

> **起始日期**不需要单独设置，它就是该人物第一段分段的戴上时间。

### 6.3 修改或删除分段

1. 统计页「分段明细」中点按某个分段
2. 可修改戴上 / 取下时间
3. 也可删除该分段（需确认）

保存时会自动校验：

- 取下时间不能早于戴上时间
- 同一人物的分段之间不能重叠
- 同一人物同时只能有一个「佩戴中」的分段

### 6.4 忘记按按钮怎么办

- **忘了按「取下」**：到统计页编辑这一段的取下时间
- **忘了按「戴上」**：用「补录」，把戴上时间填成实际时间；若现在仍在佩戴，打开「仍在佩戴中」
- **误触产生了一段**：在分段明细中删除它

## 7. 统计

### 7.1 切换月份 / 年份

统计页顶部：

- **人物切换条**：统计只显示当前人物；切换人物后，汇总、日历、图表和明细全部随之切换
- **「月」/「年」**：切换统计粒度
- **左右箭头**：切换上一期 / 下一期
- **「回到本期」**：快速回到当前月份或年份

### 7.2 月视图：日历

月视图会把数据画成一张月历：

- **格子颜色越深**：当天佩戴时间越长
- **彩色小点**：当天有对应事件类型；颜色在设置 →「事件类型」中配置
- 一天超过 3 种事件时，显示 3 个圆点加「+N」
- **图例**：显示本期有记录的事件类型
- **点按任意日期**：查看当天明细
  - 当天佩戴总时长
  - 各事件类型次数（带颜色圆点）
  - 当天的照片：以完整比例显示，点按照片可全屏查看；今天及之前的日期可上传、更换、删除，今天之后的日期只读
  - 每个分段的戴上 / 取下时间、当日计入时长
  - 当天的事件时间与备注

上传照片后，该日期格子的背景会变成这张照片；格子上的日期、佩戴时长和事件圆点仍会显示。照片支持拍照或从相册选择，会压缩后保存在本机，不联网。

日历从周一开始排列。

### 7.3 年视图：柱状图

年视图保留两张按月汇总的柱状图：

1. **佩戴时长**：12 个月的总佩戴时长
2. **事件次数**：每月各事件类型次数，按类型颜色堆叠；图例显示本期有记录的类型

点按柱子可查看该月的精确数值。

### 7.4 汇总与明细

无论月 / 年视图，页面都包含当前人物的：

- **总佩戴时长**
- **各事件类型次数**（只显示本期有记录的类型）
- **分段明细**
  - 显示该期间内每个分段的完整戴上 / 取下时间与总时长
  - 跨统计区间的分段会标注「本期计入」
- **事件明细**
  - 按日期分组
  - 点按可编辑

### 7.5 统计口径

以下口径均针对**当前人物**，不同人物分别计算：

- 佩戴时长精确到分钟，显示为「X 天 Y 小时 Z 分」
- 月 / 年总时长按**实际落在该期间的时间**切分
  - 例：10 月 31 日 22:00 → 11 月 2 日 08:00
  - 10 月计 2 小时，11 月计 32 小时
- 事件次数按事件类型分别统计；类型改名或改色后，历史记录会按新名称 / 新颜色展示
- 不采用「当天戴过就算一天」的日历天数口径

## 9. 备份与恢复

### 9.1 导出备份

1. 进入「设置」
2. 找到「数据」区域
3. 点击 **「导出备份」**
4. 选择保存位置

备份包含**全部人物、事件类型、每日随机数**及其分段、事件。**每日照片不包含在备份中**。生成的文件名类似：

```
locker-backup-20261111-2330.json
```

### 9.2 导入备份

1. 设置 →「导入备份」
2. 选择之前导出的 JSON 文件
3. 系统会显示备份中包含的人物数、事件类型数、分段数与事件数
4. 确认后选择「覆盖导入」

> 导入会**整体替换**当前所有数据（包括人物列表和事件类型），并**清空本机每日照片**，无法撤销。建议导入前先导出一份当前数据；如果照片需要保留，请单独保存原图。

> 1.1 / 1.2 导出的旧备份仍可导入：App 会自动创建默认人物「我」，旧记录归入该人物，事件类型使用内置两项。

### 9.3 备份建议

- 换手机、刷机、恢复出厂、卸载 App 之前，务必先导出
- 备份文件是**明文 JSON**，包含敏感内容，请存放在安全位置
- App 不联网，不会自动上传备份

---

## 10. 数据与隐私

- 所有人物、事件类型、分段、事件和每日照片都只保存在本机（Room / SQLite）
- 每日随机数保存在本机并进入 JSON 备份，不上传
- 每日照片会压缩后存入本机数据库，但**不会进入 JSON 备份**
- 拍照使用系统相机，App 不申请相机权限；照片读取使用系统照片选择器
- **无网络权限、无账号、无云端同步、无系统自动备份**
- 当前版本**没有 App 锁**，打开 App 不需要密码；保护依赖手机锁屏
- 卸载 App 或清除应用数据会删除全部人物的记录
- 导出的 JSON 备份包含全部人物、事件类型与每日随机数，且未加密

## 11. 常见问题

**Q：点「锁上」提示已经在佩戴中？**
A：当前人物已存在一个佩戴中的分段。到统计页把该人物的当前分段结束或删除，再重新开始；其他人物不受影响。

**Q：为什么要二次确认？**
A：锁上 / 开锁会直接影响计时，二次确认用于避免误触；确认窗口里会显示当前人物。

**Q：保存分段失败？**
A：检查三点：取下时间是否早于戴上时间；是否与**当前人物**已有分段重叠；当前人物是否已经有另一个佩戴中的分段。

**Q：日期或时间选错了？**
A：统计页点按对应分段或事件重新编辑；记录事件时可用「现在」一键设为当前时间。

**Q：App 更新后数据还在吗？**
A：在同一签名下覆盖安装会保留数据。不要卸载后再装。

**Q：换手机怎么迁移？**
A：旧手机「导出备份」→ 新手机安装 App →「导入备份」。

**Q：统计时长和实际感觉差了 1 分钟？**
A：记录精确到分钟，秒数会被舍去；可在分段编辑中把起止时间改到准确分钟。

**Q：为什么没有提醒 / 通知？**
A：当前版本不申请通知权限。忘记操作时使用补录或编辑修正。

**Q：可以同时记录多个人物吗？**
A：可以。每个人物有独立的佩戴状态、分段和事件，并且可以同时处于佩戴中。用主页 / 统计页顶部的人物切换条切换当前人物。

**Q：旧版本（1.1 / 1.2）的备份还能导入吗？**
A：可以。旧备份中的全部记录会自动归入默认人物「我」，事件类型使用内置两项；旧备份没有每日随机数，导入后会重新生成。反过来，1.7 导出的备份无法导入旧版本。

**Q：可以自定义事件名称和统计颜色吗？**
A：可以。设置 →「事件类型」→ 加号新建，填写名称并从色板选颜色。内置「锁射 / 开锁射精」也可以改名改色。

**Q：删除自定义事件类型会怎样？**
A：该类型名下、所有人物的事件记录会一并删除，无法恢复；内置类型不能删除。

**Q：日历上的颜色和小点是什么意思？**
A：格子颜色深浅表示当天佩戴时长；彩色小点表示当天有对应事件类型，颜色在设置中配置。点按日期看详情。

**Q：跨月 / 跨年的分段怎么统计？**
A：总时长按实际落在各期间的时间切分；分段明细仍显示完整分段，并标注「本期计入」。

**Q：随机数可以更换吗？**
A：不可以。每个人物每天固定一个 5 位随机数，当天首次打开 App 时生成后不再变化；第二天会生成新的号码。同一天不同人物的号码不会重复。

**Q：随机数会保存或联网吗？**
A：号码保存在本机，并进入 JSON 备份，不会上传；换手机恢复备份后，当天号码保持不变。

**Q：每日照片会进入备份吗？**
A：不会。照片只保存在本机数据库，JSON 备份不包含照片；导入备份会清空本机每日照片。需要保留照片时请单独保存原图。

**Q：为什么未来日期不能上传照片？**
A：每日照片只允许记录已经发生的日期。今天及之前的日期可以上传、更换、删除；今天之后的日期在日期详情里只读。

**Q：拍照需要给 App 相机权限吗？**
A：不需要。App 调用系统相机拍摄，不会申请相机权限；照片读取使用系统照片选择器。

**Q：安装失败？**
A：确认手机是 Android 8.0 及以上；允许安装未知来源应用；如果覆盖安装失败，确认使用的是同一签名的安装包（不要混装不同来源的构建）。

## 13. 术语表

| 术语 | 含义 |
|---|---|
| **人物** | 独立计时的对象，拥有自己的佩戴状态、分段与事件；多个人物可同时佩戴 |
| **当前人物** | 主页与统计页正在展示和操作的人物；切换后相关页面一起切换 |
| **佩戴状态** | 某个人物当前是否戴着；只有「佩戴中」和「未佩戴」两种 |
| **佩戴周期 / 分段** | 某个人物一次「戴上 → 取下」之间的连续时间 |
| **戴上 / 取下** | 分段的两个边界动作，对应开始 / 停止计时；主页按钮标为「锁上 / 开锁」 |
| **起始日期** | 某个人物第一段分段的戴上时间，不是独立字段 |
| **佩戴时长** | 当前人物各分段时长的精确累计，精确到分钟 |
| **事件类型** | 事件的分类，包含名称与统计颜色；内置类型可改名改色，自定义类型可增删改 |
| **锁射** | 内置事件类型之一，默认名称「锁射」；记录佩戴状态下发生的射精事件 |
| **开锁射精** | 内置事件类型之一，默认名称「开锁射精」；记录取下锁之后发生的射精事件 |
| **事件** | 某一事件类型的一次发生，归属于某个人物，独立于佩戴状态 |
| **每日照片** | 某个人物某一天上传的照片，作为月历格子的背景；不进入 JSON 备份 |
