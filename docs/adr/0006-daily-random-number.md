# ADR 0006：按人物与日期固定的随机数

- 状态：已采纳
- 日期：2026-11-12

## 背景

随机数原先只存在内存中，可以随时更换，无法跨设备或跨重启保持一致。需要改成「每个人物每天一个、当天不可更换、不同人物不重复」，并能在备份恢复后保持当天号码不变。

## 决策

1. 新增 `daily_random_numbers` 表，主键为 `(personId, epochDay)`，保存 `number` 与 `createdAt`。
2. 同一天不同人物的号码必须不同：对 `(epochDay, number)` 建唯一索引，生成时先查询当天已用号码，冲突则重新生成。
3. 号码范围 10000–99999，继续使用 `SecureRandom`。
4. 每天首次打开 App 时，为当前人物生成并保存当天号码；切换到其他人物时，如果该人物当天还没有号码则生成。当天已有号码时直接读取，不可更换。
5. 随机数使用设备本地日期 `LocalDate.toEpochDay()` 作为日期键；跨天后自动生成新号码。
6. 备份升级到 schemaVersion 4，新增 `dailyRandomNumbers` 数组。旧版本备份没有该数组，导入后按当天重新生成。
7. 删除人物时一并删除该人物的每日随机数；导入备份时清空并重建。

## 后果

- 当天号码无法通过界面重新生成；只能等到下一天。
- 号码随当前人物切换，不同人物在同一天不会重复。
- 备份体积增加很小（每人每天一条短记录）。
- 设备日期被手动调整时，会按调整后的本地日期生成或读取号码。
