# 本地优先存储，不做云端同步

App 只面向自己与朋友的 Android 设备，数据高度私密。我们决定数据仅保存在本机 Room/SQLite 中，App 不申请网络权限、不设账号，备份通过导出 / 导入 JSON 文件完成。换机或重装必须手动迁移。

## 考虑过的方案

- **云端同步**：换机自动恢复，但需要账号、后端、加密与合规，且敏感数据离开设备。
- **系统自动备份**：实现成本低，但数据去向不可控；已通过 `allowBackup=false` 与 `dataExtractionRules` 关闭。

## 后果

数据丢失风险由用户的手动备份承担；App 无法多设备同步。
