# ADR 0005：每日照片

- 状态：已采纳
- 日期：2026-11-12

## 背景

需要在月历中为每一天显示一张照片，作为该日格子的背景；照片按人物和日期归属，用户可以上传、更换、删除。

## 决策

1. 新增 `daily_photos` 表，主键为 `(personId, epochDay)`；照片压缩为 JPEG 后以 BLOB 保存。
2. 月历只查询当前人物、当前月份范围内的照片，避免把历史照片全部载入内存。
3. 日期详情提供「上传照片 / 更换照片 / 删除照片」；使用系统照片选择器，不申请存储权限。
4. 照片最长边限制为 1024px、JPEG 质量 80，读取时按 EXIF 方向校正。月历格子使用 `ContentScale.Crop` 并叠加半透明黑色遮罩，保证文字可读。
5. 删除人物时一并删除该人物的照片；删除单张照片只删除对应日期的记录。
6. 每日照片**不进入 JSON 备份**；导入备份时会清空本机每日照片，避免人物重建后留下孤立照片。
7. 1.5 起，随机数页也可以上传/更换**当前人物的今日照片**；今天已有照片时先确认再覆盖。
8. 每日照片只允许上传**今天及之前**的日期；未来日期在日期详情中只读，不能上传、更换或删除。
9. 照片来源支持系统相机和系统照片选择器；拍照通过 `FileProvider` 临时文件完成，App 不申请相机权限。

## 后果

- 照片会让数据库变大；压缩和按月查询控制内存占用。
- 换手机或重装时每日照片不会随 JSON 备份迁移，需要额外保留原图或后续增加照片导出功能。
- 月历格子的佩戴热力背景会被照片覆盖，但当天佩戴时长仍显示在格子中，事件圆点保留。
